## 🚀 Kurulum

### Yöntem 1: Paradox Mods (Önerilen)
[Paradox Mods sayfası üzerinden](https://mods.paradoxplaza.com/mods/159725/Windows) tek tıkla abone olarak kurabilirsiniz.

### Yöntem 2: Manuel Kurulum
1. [Releases](../../releases) sayfasından en son `TurkishLocalization.dll` dosyasını indirin.
2. Dosyayı şu klasöre yapıştırın:
   `%LOCALAPPDATA%Low\Colossal Order\Cities Skylines II\Mods\TurkishLocalization\`
3. Oyunu başlatın. Mod dili otomatik olarak Türkçe yapacaktır.

---

## ⚠️ Önemli Not
Eski v1 sürümünü (PowerShell kurulumu) kullandıysanız, çakışma olmaması için lütfen şu klasörü silin:  
`%LOCALAPPDATA%Low\Colossal Order\Cities Skylines II\Mods\TurkishLang`
